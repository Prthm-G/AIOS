# Kuanli

## Summary

WhatsApp CRM. Per the [[wiki/sources/SRC-20260724-connections-registry|connections registry]], it is the intended future home for project/task tracking, which currently has no formal system at all.

## Key facts

- Is a WhatsApp CRM ("WA CRM"). [[wiki/sources/SRC-20260724-connections-registry|SRC-20260724-connections-registry]], row 5
- Intended to fill the "Project / task tracking" domain once live — that domain currently has no formal tool. [[wiki/sources/SRC-20260724-connections-registry|SRC-20260724-connections-registry]], row 5
- Not yet connected to the AIOS as of 2026-07-24. [[wiki/sources/SRC-20260724-connections-registry|SRC-20260724-connections-registry]], row 5
