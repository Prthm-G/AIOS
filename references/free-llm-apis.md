# Free LLM API Reference

Source: [open-free-llm-api/awesome-freellm-apis](https://github.com/open-free-llm-api/awesome-freellm-apis) — MIT licensed, pure documentation. No code, nothing to install. The upstream README is auto-regenerated by a bot (tables are bounded by `BEGIN_*`/`END_*` markers), so **rate limits and model IDs below go stale fast** — check the source before relying on a specific number.

Distilled to what matters for this business: Auretris (WhatsApp bot on Cloudflare Workers), the FAQ database, and local dev. Not a copy of the directory — go to the source for the full 30-provider list.

## Read this first — the data rule

Free tiers are free because **you are paying with your data**. Most free-tier terms permit training on submitted content, and the aggregators (LLM7.io, Agnes AI, Kilo Code, Chutes.ai, Glhf.chat, OpenCode Zen) are a thin proxy layer over someone else's models — you cannot audit where a prompt lands.

Auretris handles student names, phone numbers, education history, and family financial questions. **Do not route the production WhatsApp path through a free tier.** The split to hold:

- **Free tier is fine for:** local dev, prompt iteration on synthetic or redacted threads, drafting internal copy, one-off classification of non-PII text, evaluating whether a model is good enough before paying for it.
- **Free tier is not fine for:** anything carrying a real student's message, brochure content tied to a named lead, or FAQ-DB rows joined to a contact record.

If a free provider ever does get on the production path, redact before send. That's the only control that actually holds.

## The three that fit this stack

**Cloudflare Workers AI** — highest fit by a distance. The Auretris gateway is already a Worker (`projects/manus/apps/gateway`), so this is a binding, not an HTTP call: no API key to leak, no data leaving Cloudflare, no extra vendor in the privacy story. Free allowance is neuron-based (~10K neurons/day, shared) rather than request-based, so it degrades under load instead of hard-failing. Use for cheap in-path work — intent classification, language detection, short reranking of FAQ rows before the real model sees them.
Base: binding via `wrangler.jsonc`; REST fallback `https://api.cloudflare.com/client/v4/accounts/{account_id}/ai/run`

**Google Gemini (AI Studio)** — the most generous no-credit-card tier (15 RPM / 1,500 RPD on Flash, 1M context). Best free option for *offline* batch work: summarizing brochure PDFs into FAQ rows, bulk-classifying an exported lead backlog, drafting program comparison copy. AI Studio free-tier terms have historically allowed training on inputs — keep real student data out of it.
Base: `https://generativelanguage.googleapis.com/v1beta`

**Groq** — no credit card, 30 RPM / 14,400 RPD, and the fastest tokens-per-second on the list. The reason to care is latency: a WhatsApp reply that lands in under a second feels like a person. Worth benchmarking against the current Auretris path *on redacted threads* before deciding whether a paid low-latency tier is worth buying.
Base: `https://api.groq.com/openai/v1`

Most providers here are OpenAI-wire-compatible — point the OpenAI SDK's `base_url` at them and change the model string. That makes swapping cheap, which is the actual value of this directory.

## Everything else, briefly

- **NVIDIA NIM** (123 free models, phone verification) and **ModelScope** (55 models) — the widest catalogs. Use when you need a specific open-weights model to try once, not as a dependency.
- **OpenRouter** — one key, many models, and the fastest way to A/B two models on the same prompt. Free tier is thin; the useful tier needs a one-time $10 top-up. Worth it purely as an evaluation harness.
- **Cerebras, SambaNova, Nebius, Nscale, DeepSeek, Mistral, Cohere, xAI, Z AI, Alibaba Model Studio, AI21, Hugging Face, OVHcloud, Ollama Cloud** — all real, all narrower. Check the source table when you have a specific need.
- **Local / self-hosted (Ollama, llama.cpp)** — the only option with no data question at all. The office server could host a small model for PII-heavy classification if that ever becomes the bottleneck. Slower and a maintenance burden; don't reach for it until a real privacy requirement forces it.

## Where this does not apply

Claude Code itself. The directory suggests pointing Claude Code at OpenRouter for Anthropic-compatible models — ignore that here. This AIOS runs on a Claude subscription; swapping in a free proxy would degrade the thing you actually depend on and route this repo's contents (which reference live Meta/WhatsApp credentials) through a third party.

## When to come back to this

- When picking a model for a **new** in-path Auretris step — check Workers AI first, since it adds no vendor.
- When a batch job (brochure ingestion, backlog classification) would otherwise cost real money — Gemini's free tier probably covers it.
- Before trusting any rate limit or model ID above — regenerate from the source, it moves weekly.
