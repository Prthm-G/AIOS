## P0 · The live campaign has delivered nothing for 12 days, and the cause is an exhausted prepaid balance against a spend cap

`DBU Online - 08/08/2026` (campaign `52552561899748`, objective `OUTCOME_ENGAGEMENT`) has been
switched on since **8 August 2026**. Campaign, ad set (`DBU`), and ad (`DBU`) all report
`effective_status: ACTIVE`, daily budget ₹1,000.

Delivery since it started: **zero.** No spend, no impressions.

```
insights --since 2026-08-08 --until 2026-08-20 --campaign-id 52552561899748  →  {"data":[]}
insights --date-preset last_30d                                             →  {"data":[]}
```

The account fields explain it exactly:

| Field | Value |
|---|---|
| `spend_cap` | 2499796 (₹24,997.96) |
| `amount_spent` | 2499796 (₹24,997.96) |
| `balance` | 0 |
| `is_prepay_account` | true |
| `funding_source_details.display_string` | "Available balance (₹0.00 INR)" |
| `account_status` / `disable_reason` | 1 / 0 (healthy) |

`amount_spent` has reached `spend_cap` to the paisa, and the prepaid balance is ₹0. Meta stops
delivery but leaves every object showing ACTIVE, which is why the Ads Manager status column looks
fine. This is a silent stop, not an error state.

**The fix needs two changes, not one.** Topping up the prepaid balance alone will not resume
delivery while `spend_cap` still equals `amount_spent`. The cap has to be raised or cleared as well.
Both are money decisions and belong to Pratham. Nothing here should be changed by an agent.

Recommendation: do not top up until the measurement spine is in place. Resuming spend today buys
more of exactly what the ₹24,998 already bought, which is traffic nobody can attribute. See P1.

## P1 · ₹24,998 has been spent with no conversion tracking whatsoever

Lifetime performance on this account, 1 June to 20 August 2026:

| Metric | Value |
|---|---|
| Spend | ₹24,997.95 |
| Impressions | 795,370 |
| Reach | 569,316 |
| Clicks | 4,567 |
| CTR | 0.574% |
| CPC | ₹5.47 |

All of it landed between 1 June and roughly 21 July; the last 30 days are empty.

The only dataset on the account is `WhatsApp Marketing Message Event Sharing`
(`1367623915234970`, created 2026-06-05). Its **`last_fired_time` is empty. It has never fired.**
There is no web pixel, no CAPI, and the site itself loads no analytics provider at all.

So the entire ₹24,998 produced 4,567 clicks that cannot be traced to a single lead, counselling
conversation, or admission. CTR and CPC are the only knowable numbers, and neither says anything
about whether the money worked.

This is the argument for measurement-before-spend, now with a price tag on it.
