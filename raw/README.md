# Raw sources

Drop curated source material here, then ask the agent to ingest it.

## Rules

- Files in this directory are source-of-truth inputs.
- After ingestion, do not edit, rename, move, or delete a source. Add a corrected or newer source instead.
- Keep downloaded images and attachments in `raw/assets/`.
- Prefer descriptive, stable filenames such as `2026-07-24-customer-interviews.md`.
- A source is not part of the wiki until it has a matching note in `wiki/sources/` and an ingest entry in `wiki/log.md`.

Supported inputs depend on the active agent, but Markdown, text, PDFs, images, CSV, JSON, and office documents are suitable starting points.
